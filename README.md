# 大肥鱼搜题（本地 qwen3.5-9b）

一个 Windows 桌面小工具：盯着截图文件夹，发现新截图就自动调用本机 Ollama 模型，答案直接显示在窗口里。窗口不大，带一键置顶。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `screenshot_qa.py` | 主程序（Tkinter 界面、文件夹监听、模型调用） |
| `ocr_win.ps1` | Windows 自带 OCR 组件，必须和主程序放在同一目录 |
| `assets/deepseek-whale.ico` | 桌面快捷方式和窗口使用的图标 |
| `temp/` | 分析完成后的截图缓存，首次成功分析后自动创建 |
| `题库.csv` | 本地题库（可选），CSV 格式，命中时优先使用 |
| `browser-extension/` | Edge/Chrome 插件，按题号和选项在网页上高亮 |
| `启动大肥鱼搜题.bat` | 双击启动，不弹黑色控制台 |
| `调试启动.bat` | 出问题时使用，保留控制台以便查看报错 |
| `README.md` | 本说明 |

## 运行环境

- Windows 10 / 11
- Python 3.10 及以上（本机 Python 3.15 实测通过）
- 只用 Python 标准库，**不需要 `pip install`**
- Ollama 正在运行，且已有 `qwen3.5-9b` 模型
- 系统装有简体中文 OCR（Windows 设置 → 时间和语言 → 语言 → 中文(简体) → 语言选项 → 光学字符识别）

## 使用方法

1. 确认 Ollama 已启动（托盘图标，或命令行执行 `ollama serve`）。
2. 双击 `启动大肥鱼搜题.bat`，窗口会出现在屏幕右上角。
3. 像平时一样截图，并保存到当前用户的 `%USERPROFILE%\Pictures\Screenshots`（Win+Shift+S / Fn+Win+C 截图后保存，或截图工具自动保存）。
4. 新截图出现后，程序会自动识别、调用模型，答案显示在「回答」区域。
5. 当前用户的 `%USERPROFILE%\Downloads` 会作为附加目录被监视：只分析**新出现的 `.jpeg` 文件**，其他扩展名忽略；已有旧文件不会重跑，分析后同样移入 `temp`。

预览区下方有「重新分析 / 停止 / 清空」：

- **清空**：清掉当前预览、回答和浏览器插件高亮，不会删除磁盘上的截图或 `temp` 缓存；
- 如果正在分析，点清空会取消当前任务并丢弃这次结果，避免稍后又被写回界面；
- 清空后保存新截图即可继续分析。

启动时目录里已经存在的截图**不会**自动重跑，只会把最新一张显示为预览；想分析它，点「重新分析」。

## 重要说明：文本模型与数学 OCR

本机模型 `qwen3.5-9b:latest` 的 Ollama 元数据里只有 `completion`、`thinking`、`tools`，没有视觉投影层（vision），所以它**看不懂图片像素**。

因此程序在「自动检测」模式下会这样做：

- **纯文本模型**（当前 qwen3.5-9b）：先用 Windows 自带 OCR 把截图里的文字提取出来，再把文字交给模型回答；
- **视觉模型**：先走「数学 OCR」，把图片里的题目和公式转写成文本/LaTeX，再交给答题模型作答。

对文字、代码、报错、表格类截图，普通 OCR 已经够用；高数公式、极限、分式、上下标这类内容，Windows OCR 很容易漏识别，建议使用支持视觉的模型并让自动检测走数学 OCR。如果模型名不认识但确实支持视觉，可以手动把识别模式设为「数学 OCR」。

数学 OCR 不是离线公式识别引擎，而是用视觉模型做一次“只转写、不解答”的 OCR，再把转写结果交给答题模型；因此需要模型本身支持图片输入。

## 关于速度和“思考模式”

qwen3.5 默认会先输出一大段思考过程，1200 tokens 的预算可能全花在思考上，最后没有正式答案。Ollama 的 OpenAI 兼容接口 `/v1` 目前不能可靠地关闭这个行为，所以程序优先调用 **Ollama 原生接口 `/api/chat`** 并传入 `think: false`，直接给出答案。

- 本机实测：一张 2560×1600 的截图，OCR 约 1 秒，模型约 6～12 秒给出答案；
- 如果接口地址不是 Ollama（没有 `/api/chat`），程序会自动回退到设置的 `/v1/chat/completions`，功能不受影响；
- 若回退后回答为空或只有思考内容，通常是模型思考占满了 token 预算，可以调高代码里的 `MAX_TOKENS`，或改用 Ollama 原生地址。

## 回答类型

在「设置 → 回答类型」里选择，切换类型会自动换成该类型的默认提问；手动改过的提问不会被覆盖。

- **答题**（默认）：直接回答截图中的题目，只输出题号和答案（如「1. 对」「2. B」），不解释、不复述题目、不加括号补充；判断题写「对/错」，逐题独立判断，不默认选「对」或 A；多道题按题号逐题作答。默认提问是「回答截图中的题目，只给答案，不要解释或括号补充。」
- **总结**：只对页面上出现的文字做归纳概括，输出「主题 + 要点」，不描述截图，也不讨论 OCR 识别过程。默认提问是「把页面上的文字归纳概括成要点。」
- **高情商回复**：根据截图中的对话或情境，直接写出可以发送的回复，并附一个更委婉的备选；只输出回复本身，不写分析。默认提问是「根据截图内容，帮我写一段高情商的回复。」

这三种模式都只把 OCR 文字当作材料，不会复述 OCR 结果。想让模型做别的事，直接在「提问」框里改，例如「只翻译截图里的英文」或「解释这段报错」。

## 工作流程

1. 启动时记录目录里已有文件，作为基线；
2. 每 0.9 秒扫描一次，新文件大小稳定后才处理，避免读到写了一半的图；
3. 查询 Ollama 的 `/api/show` 判断模型是否支持视觉；
4. 优先调用 Ollama 原生 `/api/chat`（`think: false`）流式显示回答；没有原生接口时自动回退到 `{接口地址}/chat/completions`；
5. 分析成功后，把截图从监听目录移动到 `temp` 缓存；点「重新分析」时从 `temp` 读取同一张图；
6. 一张处理完再处理下一张，最多排队 3 张。

## 缓存与清理

- 分析成功后，主监听目录和 `Downloads` 附加目录里的原图都会**移动**到 `screenshot-qa\temp`；`Downloads` 只处理新增 `.jpeg`。
- 点「重新分析」会读取 `temp` 里的同一张图，不会重复移动。
- 如果监听目录为空，启动时会显示 `temp` 中最新的一张；如果监听目录里也有图，则显示两边最新的一张（通常是你上次分析的那张），方便直接重新分析。
- 设置 → **清理缓存**：会显示缓存文件数量和大小，确认后删除；删除后这些图无法再重新分析。
- 缓存不会自动清理，长期使用请定期点「清理缓存」。

## 本地题库（CSV）

软件目录下的 `题库.csv` 会自动加载。格式：

```csv
题号,题目,答案,答案内容
15,使用手持电动工具时，下列哪个措施不正确？,A,使用静电防护毯
16,低压电笔一般适用于多少V以下的交流电压？,C,500
```

- `题号` 可以留空；程序主要按题目文字匹配，题号取截图里的当前题号，所以题目换位置、换编号也能对上；
- `题目` 尽量贴近原题，OCR 有少量错字也能模糊匹配；
- `答案内容` 填当前正确选项的文字（完整选项或独特关键词都可以），比如 `使用静电防护毯`、`500`；
- `答案` 填 `A`/`B`/`C`/`D` 或 `对`/`错`，作为回退；
- 程序会拿 `答案内容` 和截图里的 A/B/C/D 选项比对，**选项顺序变了也能自动映射成新的字母**；只填 `答案` 字母的话，选项一换就可能错；
- 判断题的 `答案内容` 填 `对` 或 `错` 即可；多选题用 `；` 分隔多个正确选项；
- 逐题匹配：命中的题直接用题库答案，未命中的题才交给模型；
- 模型只收到未命中的那几道题，不会再把整张图重新答一遍；最后按题号合并结果；
- 界面会显示「题库命中 X/Y 题 · 模型补答 Z 题」，方便看出哪些题走了模型；
- OCR 错字较多、题库里没有原题或题目文字差异太大时，对应题会漏命中；把原题补进题库后即可直接命中；
- 修改题库后不用重启，下一次分析会自动读取新文件；
- 设置 → 题库 → **查看** 可以直接编辑；**清空** 会清空题库（不影响 temp 缓存）；题库清空或删除后，完全走模型。

仓库只保留 1 道示例题；完整题库请自行导入。CSV 建议保存为 UTF-8（Excel 选“CSV UTF-8”）；程序也兼容 GBK 编码。

### 从 HTML 导入

设置 → 题库 → **从HTML导入**，选择题库后台保存的 HTML（例如 `实验室安全.html`）。程序按表格列解析：试题名称、试题分类、试题类型、正确答案、错误答案。

- 以 `实验室安全.html` 为例：80 道有效题 → 去重后 67 道题（46 单选、31 判断、3 多选，重复行合并）；
- HTML 里没有题号和 A/B/C/D 字母，只有正确答案文本，所以导入后靠题目文字匹配，题号用截图里的当前题号；
- 多选答案按 `；` 分隔，程序会映射成当前选项的多个字母；
- 导入时会按去掉空格和标点后的题目文字去重：HTML 里的重复行直接跳过，已有题库里的重复/无效行也会在导入时清理；
- 导入的确认框和完成提示会显示原始行数、跳过重复数、清理重复数，不会静默合并；
- 导入是合并：相同题目更新答案内容，新题追加，不会清空已有题库；
- 导入后立即生效，无需重启。

## 设置项

点右上角「设置」：

- **监听目录**：默认 `%USERPROFILE%\Pictures\Screenshots`，首次启动会自动创建
- **附加目录**：当前用户的 `%USERPROFILE%\Downloads`，只监视新增 `.jpeg`，分析后移入 `temp`
- **接口地址**：默认 `http://127.0.0.1:11434/v1`
- **API Key**：需要鉴权的 OpenAI 兼容 API 填写；会以 `Authorization: Bearer ...` 发送到当前接口地址
- **思考模式**：默认开启「远端模型非思考」，除本地 Ollama 外的请求会带 `thinking: {"type": "disabled"}`；不支持该参数的服务商会自动去掉它重试一次
- **模型名称**：默认 `qwen3.5-9b`
- **识别模式**：自动检测 / OCR 文字 / 数学 OCR（视觉模型）
- **回答类型**：答题 / 总结 / 高情商回复
- **题库**：查看 / 清空 / 从HTML导入
- **清理缓存**：删除 `temp` 中已归档的截图

配置保存在 `%APPDATA%\ScreenshotQA\settings.json`，API Key 也会保存在这个本地文件里。

### 使用 OpenAI 兼容 API

只要服务商提供 OpenAI 格式的 `/v1/chat/completions`，都可以直接接入：填接口地址、API Key、模型名即可。

DeepSeek 示例：

```text
接口地址：https://api.deepseek.com/v1
API Key：sk-你的密钥
模型名称：deepseek-flash
识别模式：OCR 文字
```

其他服务示例：

```text
OpenAI：https://api.openai.com/v1
OpenRouter：https://openrouter.ai/api/v1
本地 LM Studio：http://127.0.0.1:1234/v1
本地 vLLM：http://127.0.0.1:8000/v1
```

模型名按服务商文档填写；本地服务一般不需要 API Key。Anthropic 原生接口、Azure OpenAI 使用不同的鉴权头，不能直接按这个格式接，需要先套一层 OpenAI 兼容网关。

API Key 会以 `Authorization: Bearer ...` 发送到当前填写的接口地址，所以不要把 Key 配到不可信的地址。

DeepSeek 官方模型里，`deepseek-flash` 支持图片理解，自动检测会走数学 OCR；`deepseek-chat` 是文本模型，识别模式要选 OCR 文字。目前官方主力型号是 `deepseek-flash`（V4.1 Flash）和更贵的 `deepseek-v4-pro`；旧型号名不再作为当前推荐。

软件默认勾选「远端模型非思考」，除本地 Ollama 外都会尝试带 `thinking: {"type": "disabled"}`，避免默认 high effort 的思维链产生大量输出 token。若服务商不认识这个参数并返回 400，程序会自动去掉它重试一次；需要保留思考时取消勾选。高峰时段是北京时间周一至周五 9:00–12:00、14:00–18:00，其余时间及周末、节假日价格减半。

主界面「提问」输入框决定每次自动分析时执行什么任务，默认值会随回答类型自动变化；改完后按回车可以对当前截图重新分析。

配置保存在 `%APPDATA%\ScreenshotQA\settings.json`。

## 浏览器插件高亮

插件在网页 DOM 里按「题号 + 大肥鱼给出的选项字母」给对应选项文字加高亮，**不自动点击**。

安装（Edge / Chrome 通用）：

1. 打开 `edge://extensions`（Chrome 用 `chrome://extensions`）；
2. 打开右上角「开发人员模式」；
3. 点「加载解压缩的扩展」，选择 `screenshot-qa\browser-extension` 文件夹；
4. 保持「大肥鱼搜题」运行，打开考试页面即可。

使用说明：

- 本体会在 `127.0.0.1:8765` 提供最新答案，插件每 1.5 秒读取一次；
- 只有软件真正输出答案后才开始高亮；分析下一张截图期间保留上一次高亮；
- 下一次答案输出后，插件会先清除旧高亮，再高亮新答案；
- 页面左下角会显示「已高亮 X 题 / Y 个选项」；
- 题目渲染完成后会自动重新高亮；
- 如果显示「未连接本机软件」，确认大肥鱼搜题正在运行，且 8765 端口没有被占用；
- 插件默认只匹配 `sysaq.mju.edu.cn`，换其他考试站点时修改 `browser-extension/manifest.json` 里的 `matches`；
- 插件只高亮，不会替你点击或提交。

**高亮突然消失 / 显示「还没有答案」**

- 新版支持 `15 对`、`15. A`、`15、对`、`第15题 对` 等格式；如果刚更新过程序，必须**完全退出旧窗口并重新启动**，旧实例仍占着 8765 端口时会继续提供旧答案；
- 启动时如果提示 8765 端口被占用，说明还有一个旧窗口没关，关掉多余的实例即可。

## 按 Win+Shift+S / Fn+Win+C 自动隐藏

- 按下 `Win+Shift+S` 或 `Fn+Win+C` 时，程序通过全局键盘钩子立即隐藏窗口，避免它出现在截图里。
- Fn 键通常由键盘固件处理，Windows 看不到 Fn 本身；程序实际检测的是 `Win+C`。
- 如果键盘把 Fn+Win+C 映射成 `PrintScreen`，程序也会把它作为兜底触发隐藏。
- 截图完成（剪贴板出现图片，或监听目录出现新截图）后自动恢复；取消截图则最多 15 秒后恢复。
- 只检测 `Win+Shift+S`、`Win+C` 和 `PrintScreen`，不检测其他截图工具的热键。
- 如果键盘把 Fn+Win+C 映射成完全自定义的厂商按键，Windows 不会收到上述标准按键，这种情况下软件无法触发隐藏。
- 窗口隐藏期间程序仍在监听和分析；如果窗口没有自动回来，等 15 秒即可，或检查安全软件是否拦截了键盘钩子。

## 常见问题

**提示“无法连接模型服务”**
Ollama 没启动，或设置里的地址、模型名不对。先用 `ollama list` 确认模型存在，再确认 `ollama serve` 正在运行。

**OCR 报错“没有可用的 OCR 识别引擎”**
到 Windows 设置里给简体中文安装「光学字符识别」组件。

**识别出的文字很乱**
截图分辨率太低、字号太小、竖排文字或背景复杂都会影响 OCR。放大页面后再截图通常能改善。

**回答被截断**
默认最多生成 1200 tokens；OCR 文字超过 4000 字会被截断。可以缩小截图范围，或把提问改得更聚焦。如果确实需要长回答，可以在 `screenshot_qa.py` 里把 `MAX_TOKENS` 调大。

**窗口挡住别的内容**
点「置顶：开/关」可切换；置顶开启时按钮是蓝色。窗口位置和大小可以拖动调整。按下 `Win+Shift+S` 或 `Fn+Win+C` 时窗口会自动隐藏，截图完成后恢复。

**按 Win+Shift+S / Fn+Win+C 窗口没隐藏**
程序使用 Windows 全局键盘钩子。如果安全软件阻止了键盘钩子，隐藏会失效；可先把程序加入安全软件白名单再试。

**不想让它处理截图**
点右下角「暂停」，恢复后继续监听。

## 隐私

截图只在本机处理：OCR 由 Windows 完成，图片/文字只发送到本机 Ollama 地址，不经过外网。程序只读取监听目录里的图片，不访问其他文件。
