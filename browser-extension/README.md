# 大肥鱼ultimate（高亮 + 自动点选）

由 `screenshot-qa\browser-extension` 复制改造而来，**原目录没有改动**。原版只高亮不点击，这一版在保持高亮的同时，自动把正确答案点选上。**默认在所有网站生效**（不再只限 `sysaq.mju.edu.cn`）。

扩展管理页（`edge://extensions`）里显示的名字是 **大肥鱼ultimate**。

> ⚠️ 同一浏览器里不要再启用旧版 `screenshot-qa\browser-extension`。两个插件会同时改同一批高亮/状态栏，旧版没有“只点屏幕内”的保护，可能造成误改；确认 `edge://extensions` 里只保留本插件。

## 和原版的区别

| | 原版 | 这一版 |
| --- | --- | --- |
| 高亮正确选项 | ✅ | ✅ |
| 自动点选正确答案 | ❌ | ✅ |
| 选中项额外标记 | — | 绿色加深 + 「✓ 已选」 |
| 单选题 | 只高亮 | 点选唯一正确项 |
| 多选题（checkbox） | 不支持 | 逐项勾选，并取消明确错误的勾选 |
| 填空题（文本输入框） | 不支持 | 按题号把答案填进 `input` / `textarea`，多空按 `；` 拆分 |
| 超星/学习通作业页 | 不支持 | 支持单选、多选、判断、填空（点页面自己的选项，填空写入 UEditor） |
| 判断题（对/错） | 支持对/错 | 支持 对/错、正确/错误、是/否、√/×，兼容「A. 对」这种带字母的写法 |
| 暂停自动点击 | — | `Alt+Shift+P`，高亮不受影响 |
| 答案早于选项出现 | — | 本次只高亮，不点选 |
| 防误点保护 | — | 重试上限、点击预算、禁用/隐藏选项跳过 |

## 安装

1. 浏览器地址栏打开 `edge://extensions`（Chrome 是 `chrome://extensions`）；
2. 打开右上角「开发人员模式」；
3. 点「加载解压缩的扩展」，选择**本文件夹**（`大肥鱼浏览器插件`）；
4. 因为默认在所有网站生效，Edge 可能提示需要「读取和更改你在所有网站上的数据」，允许即可；
5. 保持「大肥鱼搜题」运行，打开考试页面即可。

> 如果之前装过 `screenshot-qa\browser-extension`，请先把它**移除或停用**。两个插件同时存在时，旧插件只高亮、新插件会点选，页面上的 `✓` 会重复，状态栏也会互相覆盖。

## 工作方式

1. 插件每 1.5 秒向本机 `http://127.0.0.1:8765/answers` 读取最新答案（后台统一代理，多个 iframe 共用缓存，3 秒超时）；
2. 按「题号 + 选项字母（或选项文字 / 对错）」找到对应选项，加绿色边框高亮；
3. **锁定到答案到达时的题目**：判断题、单选题、多选题都从 1 开始编号，同一题号可能对应多组选项。答案到达时，插件会记下屏幕上具体是哪几道题（题号 + 选项文字指纹），这批答案之后只作用于这几道题：对/错答案只落到「对/错」选项组，多字母答案只落到复选框组（多选）。屏幕外或其他题只高亮、不点选，滚动和重绘都不会回头改前面的答案；如果同号的两道题（如是非 5 和单选 5）**同时出现在屏幕上、题型又不同**，无法判断答案属于哪边，插件会只高亮、不点选并在状态栏提示；
4. 用模拟真实鼠标的事件序列点选：`pointerdown → mousedown → pointerup → mouseup → click`；
5. 单选组（radio）只点一个；多选组（checkbox）把答案里的字母逐个勾上，并把该组里**明确写着其它字母**的已勾选项取消；
6. 多选是**逐项点击**的：每点一个等 200ms 再点下一个，等页面框架把上一项写回状态，避免连续快速点击互相覆盖、最后只剩一个勾选；
7. 只有「选项组已经在页面上、答案随后到达」的题才会点选。**如果答案是先取到的、选项后渲染出来，这一批答案只高亮不点击**，避免用上一页的旧答案点新题；
8. 状态栏的「已选」标记按复选框真实状态刷新（每 1.5 秒校一次），页面自己取消勾选时不会继续显示「已选」；
9. 已经选中的选项不会重复点击；同一组选项被页面重新渲染（题号和选项文字没变）时会自动补选；
10. **填空题**：按题号找到页面上可见的 `input` / `textarea` / `contenteditable` 输入框，写入答案并触发 `input` / `change` 事件；一个题有多个空时，答案按 `；`/`、` 拆分后逐空填入，拆不出来就只填第一个空；
11. 页面左下角状态栏显示进度和版本，例如：
    `大肥鱼：高亮 3 题 / 4 个选项 · 已点选 4/4 · v1.4.2`，只有填空时显示 `已填 N 处空`，超星页显示 `超星页面已选 N 个选项 · 填空 N 处`。

插件**只点正确答案对应的选项**，不会点击提交、下一题、保存等按钮。

## 超星 / 学习通作业页

`学生学习页面.html` 这类 chaoxing 作业/测验页面不是原生 radio/checkbox，结构是：

- 题目容器 `.TiMu`，题号在 `.Zy_TItle i.fl`；
- 选项是 `ul.Zy_ulTop li[onclick="addChoice(this)"]`，字母在 `span[data]`；多选题是 `addMultipleChoice`；
- 判断题选项的 `data` 是 `true`/`false`，页面显示「对 / 错」；
- 填空题在 `.blankItemDiv` 里，用 UEditor 富文本编辑器（iframe）。

插件的处理：

- 按题号匹配答案，**点击页面自己的 `li`**，让页面自己的 `addChoice` / `addMultipleChoice` 更新选中状态和隐藏答案；
- 单选题/判断题只在目标项未选中时点；多选题逐项补齐，并取消明确不属于答案的勾选；
- 填空题优先注入一小段页面脚本调用 `UE.setContent`，失败时直接写编辑器 iframe 和隐藏 textarea；
- 题号连续（1..N），不存在同号跨大题的问题，所以**整页按题号处理**（不像 mju 那样只处理屏幕内）；富文本编辑器稍后初始化时，1.5 秒后会自动再补填一次。

> 这个页面没有「提交」按钮的自动点击，答完后仍需你自己点「保存」/「提交」。

## 安全开关

- **`Alt+Shift+P`**：暂停 / 恢复自动点选（高亮继续保留）。状态栏会变成橙色提示；
- **`Alt+Shift+D`**：把当前页面的识别结果（题号、选项类型、是否勾选、label/input 的 class）复制到剪贴板，用来排查匹配问题；复制失败时会弹出一个文本框，手动复制即可；
- 每个选项最多尝试 3 次、每次间隔至少 0.9 秒，切换不同点击目标重试；
- **10 秒内最多 30 次点击**。超过后自动停用点选并提示「页面在反复重置选项」，防止和会重置答案的页面互相打架；按 `Alt+Shift+P` 可恢复；
- 跳过被禁用（`disabled` / `aria-disabled`）和不可见（隐藏、折叠、宽高为 0）的选项；
- 答案换新时（程序输出了新答案）自动重置重试记录，重新点选。

## 状态栏提示

| 提示 | 含义 |
| --- | --- |
| `已高亮 X 题 / Y 个选项 · 已点选 a/b · v1.4.2` | 正常，a 是已选中的正确项数量；末尾是当前运行的版本 |
| `超星页面已选 N 个选项` | 超星/学习通作业页的选中数量（不是原生 input） |
| `已填 N 处空` | 当前屏幕只有填空题时，已填入的空数 |
| `N 题答案早于选项，本次未点选` | 答案先到、选项后渲染，这批答案只高亮不点选；等下一批答案即可恢复 |
| `N 题不在屏幕内，只高亮` | 这些题在可视区域外，插件不会点、也不会让页面滚动；滚动过去后会自动补点 |
| `N 题同号同屏且题型不同，只高亮` | 同一题号在屏幕上有两种题型（如是非 5 和单选 5），无法安全判断归属，需手动点一下 |
| `未匹配到选项 · 页面里没有找到单选/多选框` | 页面上没有 native 单选/多选框，或脚本没在答题所在的框架里运行 |
| `未匹配到选项 · 找到 N 个选项，但识别不到题号` | 选项找到了，但题号文字不是「1.」「1、」「第1题」这类格式 |
| `未匹配到选项 · 题号对不上（页面 …；答案 …）` | 页面的题号和程序输出的题号完全对不上 |
| `未匹配到选项 · 题号对上了，选项没匹配（答案 …）` | 题号对上了，但答案和选项文字/字母对不上 |
| `自动选择已暂停（Alt+Shift+P 恢复）` | 手动暂停了点选，高亮仍在 |
| `自动选择已停用（页面在反复重置选项…）` | 触发了点击预算保护，确认页面正常后按快捷键恢复 |
| `未连接本机软件` | 大肥鱼搜题没启动，或 8765 端口被占用 |

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 扩展清单（MV3），默认匹配所有网站（`<all_urls>`） |
| `background.js` | 请求本机答案接口，带 500ms 缓存和 3 秒超时 |
| `content.js` | 匹配题号/选项/填空，高亮 + 自动点选（核心逻辑） |
| `styles.css` | 高亮样式、已选样式、状态栏样式 |
| `icon.png` | 扩展图标 |

## 常见问题

**有高亮，但没有点选**

- 页面组件可能只认真实用户点击（`event.isTrusted`）。浏览器扩展的模拟点击无法伪造 `isTrusted`，这类页面只能手动点；
- 或选项被弹层/遮罩挡住、选项处于禁用状态；
- 单选组里答案出现多个字母时只点第一个，状态栏会提示「单选组出现多个答案」。

**想改回「只高亮、不点击」**

把 `content.js` 里 `let autoClickEnabled = true;` 改成 `false` 即可，或删掉 `applyAnswers()` 末尾两段 `applyOptionState(...)` 调用。

**状态栏显示「有答案，但未匹配到选项」**

后半句会直接写原因，通常是：

- 「页面里没有找到单选/多选框」：答题内容在别的 iframe 里，或选项是自定义组件；
- 「识别不到题号」：题号不是 `1.` / `1、` / `第1题` 这类格式；
- 「题号对不上」：页面题号和程序输出的题号完全不同，可对照后半句的两个列表；
- 「选项没匹配」：题号对上了但答案对不上选项，检查答案格式。

**多选题只勾上一个**

插件从 1.2.2 起把多选拆成逐项点击（每项间隔 200ms），并在每次点击后、以及每 1.5 秒按复选框真实状态刷新「已选」标记，避免出现「显示已选、实际没勾上」。

如果仍然只保留一个勾选，说明页面本身的选择控件或状态只允许单选 / 选择被页面重置。请按 `Alt+Shift+D` 复制诊断信息发我 —— 里面有每个 input 的 `type`、`name`、`class` 和 `checked`，可以直接判断是哪种情况。

**状态栏显示「已选」，但页面没勾上**

1.2.2 起会按真实 `checked` 状态刷新，最多 1.5 秒就会自动纠正；如果长时间不纠正，用 `Alt+Shift+D` 把诊断信息发我。

**同一个题号在多个大题里重复出现**

每个大题都会从 1 重新编号，同一题号可能对应多组选项。答案到达时，插件会锁定**屏幕上具体是哪几道题**（题号 + 选项文字指纹），这批答案只作用于这几道题；对/错答案只落到「对/错」选项组，多字母答案只落到复选框组。屏幕外或其他题只高亮、不点选，之后滚动、重绘都不会回头改前面的答案。若同号的两道题（如是非 5 和单选 5）同时显示在屏幕上且题型不同，插件只高亮、不点选。

**换考试站点 / 只在某些网站生效**

现在默认所有网站都生效，换站点不用改配置。如果想限制到指定网站，把 `manifest.json` 里的 `matches` 从 `<all_urls>` 改成对应域名（如 `https://example.com/*`），再点「重新加载」。

**在所有网站生效后要注意什么**

任何页面只要出现「题号 + 单选框/复选框/输入框」，并且本机大肥鱼当前有答案，插件就可能去点选或填值。不用时按 `Alt+Shift+P` 暂停自动点选（高亮仍在），或到 `edge://extensions` 临时关掉插件。

**考试系统选中后自动跳下一题怎么办**

这类页面会在点选后自动翻页，连续点选可能打乱题号对应关系。建议先按 `Alt+Shift+P` 暂停自动点选，只用高亮，确认当前题后再手动点；或把 `autoClickEnabled` 默认改成 `false`，只在需要时用快捷键临时打开。

**页面有倒计时、会不停刷新时**

插件会在页面重新渲染后自动补选（题号和选项文字不变才会继承原来的出现时间，同一选项最多重试 3 次，不会反复连点）；如果状态栏显示「页面在反复重置选项」，说明页面点完就清空，此时自动点选已被保护性停用，按 `Alt+Shift+P` 可恢复。

**为什么这次只高亮、没有点选**

说明答案是在选项渲染出来之前就取到的（例如刚打开页面、页面还没加载完，程序就已经有上一张截图的答案）。按设计这一批答案只高亮不点击；重新截一张当前页面的图、等程序输出新答案后，就会自动点选。状态栏会显示「N 题答案早于选项，本次未点选」。

**改了代码怎么生效**

在 `edge://extensions` / `chrome://extensions` 点本扩展的「重新加载」，再刷新考试页面。
